# 潮岬の大聖堂（SR-Super）

80 m × 50 m の岩島に建つ高さ約 149 m の大聖堂を、スマートフォンの横画面で 6 階と屋上まで一人称で散策できる WebGL 3D シーンです。

元の公開ページ: https://tidal-cathedral-3d.dnnsc097.chatgpt.site

## 動かし方

ビルド不要の静的サイトです（ES Modules を使うため、`file://` ではなく HTTP で配信してください）。

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開き、「全画面で開く」を押します。

島の地面は 72 種類の写真テクスチャを、傾斜・高さ・海岸からの距離・場所ごとのノイズで塗り分けています。

- 草地：海岸の芝、枯れ草、クローバー、タンポポ、長い草、ハマカンザシ、タイム、ヒース、ハリエニシダ、シダ、苔、泥炭、ぬかるみ
- 建物のまわり：踏み固めた小道、根の出た土、吹き寄せられた落ち葉
- 岩：地層の崖、砂岩、片麻岩、花崗岩、粘板岩、石灰岩、チョーク、玄武岩の柱、風化花崗岩の砂、ガレ場、地衣類、日陰の苔、湧き水で濡れた崖、鉄さびの岩、塩の結晶
- 海辺：砂浜、小石浜、貝殻浜、流木の浜、泥干潟、黒い火山砂、波打ち際の泡、打ち上げられた海藻、岩棚、海藻や貝の付いた岩、潮で磨かれた岩、砂丘の草、塩性湿地
- そのほか：石混じりの草地、雨に濡れた芝、瓦礫、苔むした玉石、海鳥の糞で白い岩棚、溶岩、赤い粘土の崖、海食洞の岩
- さらに：ヒナギク、アザミ、コケモモ、枯れたワラビ、羊の獣道、焼けたヒース、土手の断面、砂利道、石英の岩脈、蛇紋岩、頁岩、黄色い地衣類、風紋の砂丘、潮だまりの小石、緑藻の岩、濡れた黒い玉石、崩れかけた崖の土。地面から生える草の葉にも芝の葉のテクスチャ

大聖堂の壁・床・天井・屋根と島の塀も 63 種類の写真テクスチャ（`fabric.js`）で表しています。

- 外壁：灰色の切石を基本に、控え壁の斜面、鐘楼の荒石積み、雨だれの筋、北側の苔と塩じみ、足元の黒ずみ。窓や尖塔の刳形、花崗岩の基壇
- 内壁：明るい石灰岩、アーケードの束ね柱、祭壇上の煤、5・6 階の白い漆喰、2 階より上の壁の下部はオークの腰板。リブは迫石
- 床：身廊の敷石、交差部の市松大理石、緑と白の大理石、オーク、上階の側廊のテラコッタ、屋上テラスの石板、階段の石段、側廊の墓石
- 天井・屋根：ヴォールトは雨染みの漆喰、翼廊の礼拝堂は漆喰の交差ヴォールト、宝物庫と写字室は梁天井、古文書室は漆喰、鐘室は煤けた梁、地下礼拝所はリブ・ヴォールト。スレート屋根（低い所は苔むした石板）、鉛板屋根、管理小屋の鉛の雨どい
- 側廊のタペストリーと壁画、地下の柱頭
- 追加の外壁：足元のルスティカ、海側の塩の浸食、テラス下の緑青の筋、窓のくぼみ、鉄鋲の扉、土台の擁壁
- 追加の内壁：アーケード上の縞大理石、各階の天井下の壁画帯、1 階の端の壁のブラインドアーケード、後陣の金モザイク、東の階段沿いの落書き、鐘室の青い漆喰、入口内側の聖人の壁龕、写字室の木の格子、上階側廊の浮彫り天井
- 島と屋上：前庭の白壁の番小屋（扉・鉄格子の窓・羽板）、庭の塀、石の手すり、島の両側の乾式石垣と丸石の石垣、屋上の胸壁、管理小屋の剥げた漆喰と羽板、井戸の内壁、地下の湿った漆喰と石段の側壁

## テクスチャの生成

`.claude/skills/sunburst-textures/` のスキルで、GPT Image 2.5 Sunburst（`gpt-image-2.5-sunburst`、1:1・2880×2880・quality `xhigh`）の画像を 3×3 に分割し、1 枚から 9 種類のテクスチャを作ります。手順は `SKILL.md` を参照してください。API キーは環境変数 `OPENAI_API_KEY` で渡し、リポジトリには保存しません。

## 主なファイル

| --- | --- |
| `index.html` / `style.css` | 入口画面・HUD・設定ダイアログ |
| `main.js` | 起動処理、入力（移動パッド・視点ドラッグ）、テクスチャ読み込み |
| `renderer.js` / `shaders.js` | WebGL レンダラーと GLSL シェーダー |
| `cathedral.js` / `ornament.js` / `furnishings.js` | 大聖堂本体・装飾・調度品のメッシュ生成 |
| `terrain.js` / `layout.js` / `walkways.js` | 岩島の地形、建物配置、歩行経路と階の移動 |
| `character.js` / `mesh.js` / `surfaces.js` | 人物、メッシュ用ユーティリティ、表面素材の定義 |
| `chapels.js` | 新しい部屋とオブジェクト（洗礼堂・船乗りの礼拝堂・宝物庫・写字室・屋上庭園・前庭） |
| `crypt.js` | 地下聖堂（潮の回廊・石棺の間・地下礼拝所）と 1 階からの階段 |
| `landcover.js` / `terrain-128.webp` / `terrain-320.webp` | 地形の 72 種類のテクスチャ |
| `fabric.js` / `fabric-128.webp` / `fabric-256.webp` | 大聖堂の壁・床・天井・屋根と塀の 63 種類のテクスチャ |
| `decor.js` / `decor-96.webp` / `decor-256.webp` | 部屋の素材 72 種類のアトラスと素材 ID |
| `textures/` | 生成に使ったシート定義（`specs/`）、生成画像（`sheets/`）、アトラス構成（`decor-atlas.json`） |
| `.claude/skills/sunburst-textures/` | テクスチャ生成スキル（生成 → 3×3 分割 → シームレス化 → アトラス化） |
| `*.webp` | 素材アトラス（低解像度・高解像度）、ステンドグラス、祭壇画、カバー画像 |
| `manifest.webmanifest` / `sw.js` / `icon-*.png` | PWA 設定とオフライン用 Service Worker |
