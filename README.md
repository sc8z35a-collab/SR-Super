# 潮岬の大聖堂（SR-Super）

80 m × 50 m の岩島に建つ高さ約 149 m の大聖堂を、スマートフォンの横画面で 6 階と屋上まで一人称で散策できる WebGL 3D シーンです。

元の公開ページ: https://tidal-cathedral-3d.dnnsc097.chatgpt.site

## 動かし方

ビルド不要の静的サイトです（ES Modules を使うため、`file://` ではなく HTTP で配信してください）。

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開き、「全画面で開く」を押します。

## 地下 2〜7 階（`depths.js` / `under.js`）

地下1階（潮の地下聖堂）の東側の通路から、階段が左右の壁沿いに交互に続きます。最下層の地下大聖堂へは、地下6階の西側から大階段で下ります。「階を選ぶ」から各階へも直接行けます。

| 階 | 内容 |
| --- | --- |
| 地下2階 · 大貯水槽 | 水から立つ苔むした円柱の林、板の歩道、排水口、手押しポンプ、錆びた配管、硬貨の沈む泉 |
| 地下3階 · カタコンベ | 埋葬棚と頭蓋骨の壁が続く2本の回廊、骨の装飾、赤い顔料の壁画、墓碑、棺、頭蓋骨の壁の納骨堂の祭壇 |
| 地下4階 · 坑道 | 坑木の支保工とトロッコの線路、鉱車、石炭層と鉄鉱床、残し柱、昇降機の檻、滑車、梯子、ふさがれた螺旋階段 |
| 地下5階 · 水晶洞窟 | 紫水晶・水晶・蛍石・光る青い結晶の群晶、黄鉄鉱、晶洞、光る苔と光るキノコ |
| 地下6階 · 地底湖 | 透き通った地底湖と白い砂の湖底、滝と霧、リムストーン、鍾乳石と石筍、温泉と硫黄、溶岩ガラス |
| 地下7階 · 地下大聖堂 | 岩塩の壁と柱、星空の天井画、岩塩のドーム、琥珀の窓、聖人像、信者席、説教壇、結晶のシャンデリア、内陣の祭壇と金の光輪のモザイク、聖歌隊席 |

階ごとに光源（松明・ランタン・光る結晶など）の位置と色を持ち、シェーダーがその階の光だけで照らします。地下2階より深い所では、地上の建物・海・空は描きません。

## 描画設定

右上の設定ボタンから変えられます。選んだ値はブラウザに保存されます。

| 項目 | 選択肢 |
| --- | --- |
| 描画解像度 | 240p / 320p / 400p / FHD（1080） / 2K（1440） / 4K（2160）。GPU の上限を超える場合は自動で縮めます |
| フレームレート | 30 / 60 / 120 / 無制限（画面のリフレッシュレートが上限） |
| 反射 | 反射なし / 反射あり（大聖堂と島を海面に映す鏡面パス。半分の解像度で描きます） |
| 描画距離（チャンク） | 1〜10 のバー。島の小物・岩・草は 12 m 四方のチャンクに分かれており、半径 16〜200 m の範囲だけを描きます。建物の中では上下 1〜6 階を描きます |
| 描画品質 | 高品質 / 軽量 / 最軽量 |
| HDR | 浮動小数点のバッファに描き、明るい部分をにじませてからトーンマッピングします（`EXT_color_buffer_float` が必要） |

テクスチャは、大きな面で約 1/3.5、小物で約 1/6 の GPU メモリに抑えています（高品質で 157.5 MB → 41.6 MB）。細い棒や小さな部品は大きさに応じて角の数を減らし、組み上がる三角形は約 36 万 → 約 27.5 万です。

## 金属・窓・海・調度・島の小物（`props.js`）

- 金属：鐘・燭台の青銅、鋳鉄、真鍮、緑青の銅板、金箔、錆びた鎖、門の渦巻き鉄、ピューター、宝箱の鋲打ち帯金
- 窓：場所ごとに聖人・船・幾何学模様・従来のステンドグラスを選び、正面はバラ窓、5 階より上は菱形の鉛ガラス・古い緑のガラス・ひび割れたガラス。素通しの尖頭窓の頭部は石の網目飾り、外側には雨粒
- 海：沖の深い海、岩場の浅瀬、昆布の森、北西沖の渦潮、波の泡と引き波、夕日のきらめき、船着き場側の濁った水。波打ち際の岩には流れ落ちる海水、地下の水路は濁った海水
- 堂内：信者席のオークと赤いひざ置き、交差部の説教壇、緑の祭服、東の側廊のパイプオルガンと譜面台、聖歌集、献金箱、入口の聖水盤

## テクスチャの生成

`.claude/skills/sunburst-textures/` のスキルで、GPT Image 2.5 Sunburst（`gpt-image-2.5-sunburst`、1:1・2880×2880・quality `xhigh`）の画像を 3×3 に分割し、1 枚から 9 種類のテクスチャを作ります。手順は `SKILL.md` を参照してください。API キーは環境変数 `OPENAI_API_KEY` で渡し、リポジトリには保存しません。
